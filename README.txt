모던 테니스매니저 배포 폴더

- 이 폴더 안의 파일을 '그대로' 호스팅(예: Vercel 프로젝트 / cafe24 / S3 등)에 업로드하세요.
- 같은 도메인에서 하위 경로로 올릴 경우(예: /accounting/), 폴더 자체가 경로가 되도록 올리면 됩니다.

✅ 데이터 분리:
- 이 앱은 Firebase 경로를 앱 전용 네임스페이스로 분리했습니다.
- 최초 1회 실행 시, 기존 공용 데이터에서 필요한 데이터만 자동 복사(마이그레이션)합니다.

✅ 2026-09-18 선수별 핸디 기능:
- 관리자가 매치 참가자별로 핸디 0/+1/+2를 지정할 수 있습니다.
- 복식 팀에는 두 선수 중 높은 핸디가 자동 적용됩니다.
- 각 경기에서 관리자가 팀 핸디를 예외적으로 수정할 수 있습니다.
- 경기 결과와 순위에는 핸디 포함 최종점수를 반영합니다.
- 기존 경기 기록은 핸디 0으로 호환됩니다.
